# Doodles de Hilario e Ilaria

Coloca en esta carpeta los dos PNG finales, conservando exactamente estos nombres:

- `Hilario.png`
- `Ilaria.png`

Usa imágenes con fondo transparente y deja un poco de aire alrededor del dibujo. Una proporción vertical cercana a 4:5 y al menos 600 px de alto dará buen resultado. La web detectará los archivos nuevos y sustituirá los dibujos provisionales automáticamente.
